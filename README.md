# UE5 RPG Practice

这是一个基于 Unreal Engine 5.6 的第三人称 RPG 原型项目，主要使用蓝图完成角色控制、近战战斗、装备、任务、AI、UI 和开放世界场景相关功能。

## 已实现功能

### 角色控制

- 基于 Enhanced Input 的移动、视角、跳跃、冲刺、蹲伏与翻滚闪避。
- 角色朝向、移动动画、相机跟随和基础操作手感整合。
- 攀爬、跨越障碍、游泳等动作模块，包含对应输入、动画资源和蒙太奇。
- 物体投掷交互，以及潜行暗杀提示与暗杀动画流程。

### 战斗系统

- 近战攻击输入与攻击检测组件。
- 基于动画通知的武器挥砍判定窗口。
- 敌人受击、伤害反馈、血量变化和死亡动画资源。
- 目标锁定、翻滚闪避、剑击音效、受击音效、血量 UI 和相机震动反馈。
- 弓箭瞄准与射击动画资源，包含弓箭输入和瞄准偏移动画。

### 属性与 UI

- 玩家状态组件，覆盖生命值、体力、经验和等级等基础 RPG 数值。
- HUD、玩家血量/体力显示、敌人血条、Boss 血条和调查提示。
- 经验升级相关音效与 UI 反馈资源。
- 伤害边框、图标、字体和基础交互控件资源。

### 装备与物品

- 装备系统组件、物品蓝图、物品数据表、武器类型枚举和装备槽结构。
- 装备界面、物品槽、装备槽和角色预览 Render Target。
- 剑、盾、弓、护甲等装备资源。
- 武器拾取、装备切换和角色身上装备显示所需的资源结构。

### 任务系统

- 任务组件、任务给予者接口和任务给予者蓝图。
- 任务数据结构、任务目标结构和任务 UI。
- 任务 HUD、任务列表、任务目标、对话窗口和交互确认窗口。

### AI 与敌人

- 通用 AI、Boss AI 和平民 AI 蓝图。
- 行为树、黑板、AI Controller 与行为树接口。
- 巡逻、追踪、攻击、距离检测和调查值清理等行为树任务/服务。
- Boss 血条和敌人血条 UI 资源。

### 动物与环境交互

- 动物基础蓝图，以及大象、河马等动物角色资源。
- 动物移动、攻击、受击、死亡和休息等动画资源。
- 动物音效和脚步音效资源。

### 场景与开放世界资源

- `Action_Test`、`Desert`、`Desert1` 等关卡。
- 沙漠场景、村庄模块化建筑、水体、植被和开放世界模板资源。
- Landmass、Water、Motion Warping 等 UE 插件已在项目中启用。

## 项目结构

```text
Config/                         项目输入、渲染和引擎配置
Content/AI/                     AI 蓝图、行为树、黑板和任务
Content/BluePrint/              角色状态、攻击、任务、交互和通用蓝图
Content/Equipment_System/       装备组件、物品数据、装备 UI
Content/Quest_System/           任务组件、任务给予者、任务 UI
Content/Input/                  Enhanced Input 输入映射和动作
Content/UI/                     HUD、血条、提示和 UI 资源
Content/Weapons/                剑、盾、弓等武器资源
Content/Armor/                  护甲资源
Content/Levels/                 测试关卡和开放世界关卡
Content/Characters/             角色骨骼、动画、攀爬、游泳、弓箭、暗杀等资源
Content/AfricanAnimalsPack/     动物角色、动画、材质和音效资源
```

## 运行环境

- Unreal Engine 5.6
- 主要实现方式：Blueprint
- 输入系统：Enhanced Input
- 已启用插件：Motion Warping、Water、Landmass、Gameplay StateTree、Modeling Tools Editor Mode

## 当前状态

项目已经形成一个可继续扩展的第三人称 RPG 原型框架，核心系统覆盖角色操作、战斗反馈、装备/任务 UI、AI 行为和开放世界场景搭建。后续可以继续补强任务内容、敌人行为细节、装备数值、存档流程和整体关卡玩法闭环。
